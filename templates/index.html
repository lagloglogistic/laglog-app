Einstellungen
Schnellauswahl Anbieter
IONOS / 1&1: Host: smtp.ionos.de · Port: 587 · Benutzername = vollständige E-Mail-Adresse
Wichtig: Bei IONOS muss der Benutzername die vollständige E-Mail-Adresse sein (z.B. info@firma.de), nicht nur der Name.
Gmail: Host smtp.gmail.com · Port 587 · Benutzername = Gmail-Adresse · Passwort = App-Passwort (Google-Konto → Sicherheit → 2-Schritt-Verifizierung → App-Passwörter), nicht das normale Passwort.
Outlook / Microsoft 365: Host smtp.office365.com · Port 587 · Benutzername = komplette Adresse · „Authentifiziertes SMTP“ muss im Postfach aktiviert sein. Privat (Outlook.com/Hotmail): smtp-mail.outlook.com mit App-Passwort.
Ohne Server-Zugang: Im Menü ✉ E-Mail gibt es auch Entwurf (.eml), Gmail- und Outlook-Web-Versand ganz ohne diese Einstellungen.
